# Skill: Pruebas funcionales
Objetivo: mantener funcionalidad existente.
1. Inventariar rutas críticas, botones, filtros, estados, persistencia, cargas, descargas y errores.
2. Proponer pruebas para flujos principales y regresiones ya reportadas.
3. Ejecutar localmente solo pruebas seguras y disponibles; separar pruebas no ejecutadas.
4. No reemplazar datos reales por ejemplos ni forzar importaciones.
5. Registrar resultado, reproducción y evidencia breve por prueba.
