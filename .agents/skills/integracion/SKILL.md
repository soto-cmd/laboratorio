# Skill: Integración segura
Objetivo: preparar PR sin dañar funcionalidades existentes.
1. Identificar rama base, cambios solapados, dependencias y compatibilidad.
2. Diseñar secuencia de integración, checklist de regresión y rollback.
3. Mantener commits pequeños, sin reescrituras amplias ni force push.
4. Comprobar CI y pruebas si existen, sin inventar resultados.
5. Nunca fusionar ni desplegar automáticamente; entregar PR listo para aprobación.
