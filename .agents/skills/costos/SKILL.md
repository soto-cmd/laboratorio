# Skill: Optimización de planes gratuitos
Objetivo: reducir uso de Vercel, Neon, Supabase y GitHub Actions.
1. Detectar cron excesivos, polls repetidos, builds innecesarios y consultas costosas.
2. Favorecer ejecución por eventos, caché con invalidación segura, paginación y límites.
3. Estimar beneficios sin inventar métricas ni límites vigentes.
4. No desactivar alertas, seguridad, backups o controles para ahorrar recursos.
5. Consolidar cambios para una sola validación/build cuando sea razonable.
