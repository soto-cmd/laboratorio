# Skill: Protección de datos
Objetivo: impedir pérdida de información y regresiones de esquema.
1. Identificar entidades, escrituras, relaciones, importaciones y consumidores afectados.
2. Documentar respaldo requerido, identificador, fecha, versión, restauración y rollback.
3. Verificar compatibilidad hacia atrás y migraciones idempotentes antes de proponer cambios.
4. Usar datos ficticios para pruebas; no leer, exportar ni modificar datos sensibles innecesariamente.
5. Nunca ejecutar borrados, migraciones o cambios de producción sin aprobación.
